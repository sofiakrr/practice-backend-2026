# Cafe Booking API

## Описание проекта

REST API для системы бронирования столиков кафе.
Пользователи бронируют столики на определённое время.
Администратор управляет столиками и всеми бронированиями.

**Предметная область:** Кафе  
**Стек:** PHP (Laravel), MySQL  
**Аутентификация:** JWT

## Столики и зоны

| Название | Тип | Мест | Расположение | Цена/час |
|---|---|---|---|---|
| Столик у окна | standard | 2 | Основной зал | 200 ₽ |
| Круглый столик | standard | 4 | Основной зал | 300 ₽ |
| VIP-кабинка | vip | 6 | VIP-зона | 800 ₽ |
| Столик на террасе | terrace | 4 | Терраса | 400 ₽ |
| Приватный зал | private | 15 | Отдельный зал | 1500 ₽ |

## Роли

| Роль | Возможности |
|---|---|
| admin | Управление столиками, просмотр всех броней |
| user | Бронирование столиков, свои брони, отзывы |

## Запуск проекта

1. `composer install`
2. Скопировать `.env.example` в `.env`
3. `php artisan key:generate`
4. `php artisan jwt:secret`
5. Настроить БД в `.env`
6. `php artisan migrate:fresh --seed`
7. `php artisan serve`
