## Чекпоинт 4 — Расписание, поиск, отзывы

### Что реализовано

- Расписание столика на день и на неделю
- Поиск свободных столиков на заданную дату и время
- Фильтрация ресурсов по характеристикам (тип, вместимость, цена, расположение)
- Пагинация, фильтрация и сортировка по единым правилам для всех списков
- Отзывы с оценкой (только после завершённого бронирования)
- Защита от повторного отзыва и отзыва по чужому бронированию
- Средний рейтинг ресурса в каждом ответе API

---

### Новые эндпоинты

| Метод | URL | Кто может | Описание |
|---|---|---|---|
| GET | `/api/resources` | Авторизован | Список с фильтрами, сортировкой, пагинацией |
| GET | `/api/resources/available` | Авторизован | Поиск свободных столиков |
| GET | `/api/resources/{id}/schedule` | Авторизован | Расписание на день или неделю |
| GET | `/api/resources/{id}/reviews` | Авторизован | Отзывы + средний рейтинг |
| POST | `/api/resources/{id}/reviews` | Авторизован | Добавить отзыв |

---

### Параметры запросов

#### GET `/api/resources`

| Параметр | Описание | Пример |
|---|---|---|
| `type` | Фильтр по типу | `?type=vip` |
| `capacity` | Минимальная вместимость | `?capacity=4` |
| `max_price` | Максимальная цена/час | `?max_price=400` |
| `location` | Поиск по расположению | `?location=терраса` |
| `sort_by` | Поле сортировки | `?sort_by=price_per_hour` |
| `sort_order` | Направление (asc/desc) | `?sort_order=asc` |
| `per_page` | Элементов на странице | `?per_page=3` |
| `page` | Номер страницы | `?page=2` |

#### GET `/api/resources/available`

| Параметр | Обязательный | Описание |
|---|---|---|
| `date` | ✅ | Дата (не раньше сегодня) |
| `start_time` | ✅ | Время начала (HH:mm) |
| `end_time` | ✅ | Время окончания (HH:mm) |
| `capacity` | ❌ | Минимальная вместимость |
| `type` | ❌ | Тип столика |

#### GET `/api/resources/{id}/schedule`

| Параметр | Обязательный | Описание |
|---|---|---|
| `date` | ✅ | Дата |
| `mode` | ❌ | `day` (по умолч.) или `week` |

---

### Единые правила для всех списков

| Эндпоинт | Пагинация | Фильтрация | Сортировка |
|---|---|---|---|
| `GET /api/resources` | ✅ | ✅ type, capacity, price, location | ✅ sort_by, sort_order |
| `GET /api/resources/available` | ✅ | ✅ capacity, type | — |
| `GET /api/resources/{id}/reviews` | ✅ | — | ✅ по дате desc |
| `GET /api/bookings` | ✅ | — | — |

---

### Бизнес-правила отзывов

- Отзыв можно оставить **только по своему бронированию**
- Отзыв можно оставить **только после завершения** бронирования (дата и время уже прошли)
- **Нельзя оставить два отзыва** на одно бронирование → 422
- Нельзя оставить отзыв по чужому бронированию → 403

---

### Средний рейтинг в ответах API

**GET `/api/resources`** и **GET `/api/resources/{id}`:**
```json
{
  "id": 1,
  "name": "Столик у окна",
  "reviews_count": 3,
  "reviews_avg_rating": 4.3
}
```

**GET `/api/resources/{id}/reviews`:**
```json
{
  "resource": "Столик у окна",
  "average_rating": 4.3,
  "reviews": { ... }
}
```
